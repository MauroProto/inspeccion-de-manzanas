# Inspección de manzanas

Trabajo final de Aprendizaje Automático II, Universidad de San Andrés. YOLO11n detecta las manzanas, ByteTrack las sigue y las redes convolucionales estiman su variedad y el daño visible. En los videos de planta, esas predicciones no se verificaron por manzana.
