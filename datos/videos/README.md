El repositorio también conserva los tres MOV originales y las copias previas en `datos/videos/`. Los tres clips del Food Safety Resource Clearinghouse se atribuyen a Alison Work, con uso no comercial según sus fichas. El repositorio de Coral indica Apache 2.0. La licencia específica del clip de `apple_counting` sigue sin verificarse.

Los cinco clips se pueden usar para observar el sistema y medir velocidad. Para calcular aciertos en video hacen falta etiquetas de referencia. [AppleMOTS](https://zenodo.org/records/5939726) es una fuente posible para evaluar seguimiento en huertos.
